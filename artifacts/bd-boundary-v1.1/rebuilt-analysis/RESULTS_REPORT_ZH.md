# B/D 边界修订独立评价结果

三名匿名评价者完成 24 张卡，共 72 次判断。旧规则与评价者选择一致 52/72（72.2%），修订规则一致 68/72（94.4%），差值为 +22.2%；冻结主分析按全部卡片聚类的 10,000 次 bootstrap 95% 区间为 +6.9% 至 +38.9%。保持 6/6/4/4/4 抽样配额的分层卡片聚类 bootstrap 敏感性区间为 +19.4% 至 +25.0%。

B→D 层共 18 次判断，其中 16 次选择 D，2 次选择 A；稳定层 54 次判断中 52 次与修订规则一致（96.3%）。24 张卡中，三人多数票与 v1.1 一致 24/24，20 张三人全体与 v1.1 一致。评价者间 nominal Krippendorff’s α=0.848，Fleiss’ κ=0.846。置信度中位数为 5。

这些数字支持在本组受控测量情景中把“测量语义已经明确、历史与上下文证据也足够”的候选从 B 调整到 D。它们不证明正式 SLO 已获批准，也不是生产效果检验；卡片中的 M1—M4 说明部分属于基于真实候选构造的实验给定条件。
