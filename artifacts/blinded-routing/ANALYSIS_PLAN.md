# 冻结分析计划

## 分析数据集

主要分析集包括满足纳入条件、完成全部 32 张卡并确认盲态独立完成的 3 名新评价者。任何卡片不得因分歧、低信心、长耗时或不利结果而删除。

若存在技术性缺失，主要分析仍采用完整评价者；所有可用判断可作为明确标注的敏感性描述，不替代主要结果。

## 主要分析

对每个第一阶段判断定义：

```text
agreement = 1，当且仅当 blinded_choice == frozen_protocol_choice；否则为 0。
```

报告：

1. 一致判断数/全部专家—卡判断数；
2. 一致率；
3. 以卡片为聚类单位的 10,000 次 bootstrap 95% 区间，种子 `20260814`。

不设置事后显著性检验或根据结果选择“通过门槛”。

## 补充分析

- 卡片多数票：3 名评价者中至少 2 人选择的路径；报告 32 张卡中多数票与协议一致的张数。
- 分路由结果：A/B/C/D 各 8 张、24 个专家—卡判断，报告一致数和比例。
- 混淆矩阵：行是冻结协议处置，列是盲态评价者选择。
- 评价者一致性：Krippendorff nominal α 和 Fleiss κ。四类路径按名义变量处理。
- 难度分层：明显与临界/重叠案例只作描述性比较，不做多重假设检验。
- 信心与耗时：报告中位数和四分位区间；分别描述一致与不一致判断。
- 揭示后结果：报告 `unchanged`、`changed_to_protocol`、`changed_away_from_protocol` 数量；重点描述初始不一致判断有多少改为协议路径。

## 缺失与异常

- 选择必须为 A/B/C/D；其他值视为缺失，不进行推断性填补。
- 信心必须为 1—5；越界值标记为无效，但不删除该卡的处置选择。
- 负耗时或明显的计时系统错误标记为缺失；不据此删除处置选择。
- 自由文本只用于解释边界案例，不作为量化主张来源。

## 报告边界

允许表述：评价者在盲态下与冻结协议的处置一致程度、分歧主要出现在哪类卡、揭示后是否改判。

禁止表述：协议证明了阈值正确、专家形成可靠总体共识、治理改善了真实决策、节省了工作时间、提高了 SLO 质量或获得跨组织外部有效性。
