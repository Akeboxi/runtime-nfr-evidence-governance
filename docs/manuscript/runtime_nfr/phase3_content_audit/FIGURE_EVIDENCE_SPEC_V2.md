# 核心图证据重构规格（内容门通过后执行）

本文件定义后续图片应承载的论证，不授权新增实验或装饰性美化。

## F1：首页问题—机制图

**唯一主张：** 相同或接近的候选数值并不产生相同的需求责任动作。

**建议面板：**

- a：三类冻结原始遥测窗口缩略图——覆盖缺口、零错误/分辨率、长尾延迟；
- b：对应候选卡的数值、覆盖、样本、稳健尺度和尾差；
- c：证据状态→治理动作，并明确“候选≠SLO”。

**数据来源：** 现有代表卡及其冻结 `history_start/history_end` 原始路径。  
**不得暗示：** 三个案例代表总体频率；治理动作等于业务批准。

## F2：threshold-only 到治理状态的决策流

**唯一主张：** threshold-only 保留数值，却无法表达 4,426 张卡的补证、未解析或上下文审查责任。

**建议面板：**

- a：8,668 个 threshold-only 数值输出流向四状态；
- b：history/resolution/tail 的独立触发和交集；
- c：删除/换序规则导致的状态迁移数量。

**不得使用：** “错误放行率”“准确率提升”“治理优于”。

## F3：硬边界反例

**唯一主张：** 10.0 是责任触发器，不是自然真值。

**必须包含：**

- 9.997 与 10.035 两张卡的原始尾部分布或时间序列；
- 9.5/10.0/10.5 的 9/0/19 迁移；
- 专家对 9.997 卡提出 `STATE_ERROR` 的匿名化摘要。

该图把规则敏感性与真实反对意见连接起来，比只画敏感性柱状图更能证明边界意识。

## F4：专家证据

**唯一主张：** 专家评价的是治理处置，而不是批准原始阈值。

**建议面板：**

- a：48 张卡的阈值—治理配对斜率；
- b：按四状态的配对差分布；
- c：修复/留出队列和唯一反例标记。

负 α、天花板效应和 `candidate_for_stakeholder_review` 状态中较小的中位差必须可见。

## F5：外部拒绝

当前结构基本满足要求。保留字段缺失、360—2,100 s 历史、86,400 s 门禁和 1,250/1,250 拒绝链。不要继续增加外部数据或把“全拒绝”画成性能成功。

## F6：预测边界

**唯一主张：** 应用遥测存在支持性排序信号，但概率校准和服务异质性限制其独立解释。

**建议面板：**

- a：五折 PR-AUC 与服务范围；
- b：事件级配对差值森林图；
- c：App Logistic/HGB 的可靠性曲线及 Brier/ECE。

拓扑覆盖和静态性可移入紧邻表格或补充材料，避免同一图同时承担预测、校准和拓扑三项主张。
