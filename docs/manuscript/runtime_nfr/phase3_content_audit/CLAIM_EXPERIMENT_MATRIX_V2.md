# Runtime NFR Claim–Experiment 矩阵（阶段二后）

## 1. 论文主线

**一句话主张：** 缺少显式 SLO 时，历史遥测只能形成候选边界；将候选与证据充分性、拒绝理由、责任路由和利益相关者批准权绑定，能够避免把历史表现静默升级为规范目标。

**贡献类型：** 证据治理协议＋实证研究。不是新的阈值估计算法、预测模型或外部迁移算法。

**最强可证伪机制：** 若证据状态没有实质作用，则 threshold-only 与治理输出的责任动作应无差异，删除/换序规则不应改变状态，专家也不应系统区分阈值可信度和治理适当性。

## 3. 实验角色去重

| 实验 | 在论文中的唯一角色 | 不应承担的角色 |
| --- | --- | --- |
| threshold-only | 证明治理层增加了哪些证据/责任信息 | 阈值准确率或业务效用基线 |
| 规则反事实 | 解释每条冻结规则实际改变哪些处置 | 搜索最优门槛或证明规则正确 |
| 第二轮专家 | 判断专家是否区分数值可信度与处置适当性 | 利益相关者批准、因果改进 |
| 人工核查 | 验证匹配实现和证据能否重建 | 科学效度、阈值正确性 |
| RCAEval | 验证接口和拒绝门禁在协议不兼容时是否保持 | 正向外部有效性 |
| 预测消融 | 检查标签附近是否存在故障前支持信号 | 新预测算法或构念验证 |
| 拓扑审计 | 界定当前表示的负结果范围 | 否定拓扑或 GNN |

## 4. 最小正文主证据

正文主线只需要四个连续判断：

1. 可生成候选，但候选不是 SLO；
2. threshold-only 会隐藏 51.1% 卡片的证据责任；
3. 删除/换序规则确实改变处置，且固定阈值附近存在反例；
4. 专家总体区分阈值与治理，同时保留一条明确边界异议。

人工、外部、预测和拓扑用于说明“证据链能被信任到哪里”，不再扩展为并列贡献。
