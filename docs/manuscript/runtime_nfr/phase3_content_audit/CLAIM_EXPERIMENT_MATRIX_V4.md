# Runtime NFR Claim–Experiment 矩阵（v0.7 最终定向复核）

日期：2026-07-30

正文版本：`v0.7-final-review-polished`

## 核心命题

缺少显式 SLO 时，历史遥测可以形成需求候选，却不能自行取得目标批准权。
本文的贡献是把候选生成、证据审计、失败保持的治理动作和人工批准权连接成
可复核的责任链，使“何时可转交、何时应停止”成为方法输出。

该命题不包含阈值统计最优、正式 SLO 自动生成、生产环境普遍有效、独立预测
模型创新或拓扑/GNN 普遍无效等主张。

## 证据角色去重

| 证据 | 唯一职责 | 不承担的职责 |
| --- | --- | --- |
| threshold-only | 显示治理层增加的证据状态与责任路由 | 阈值精度或业务效用基线 |
| 规则反事实 | 显示冻结政策改变哪些状态及迁移目的地 | 选择最优门限或证明规则正确 |
| 专家配对评价 | 检查两类评价对象能否被区分 | 利益相关者批准、总体批准率或因果改进 |
| 人工重建 | 核查匹配实现和证据重建 | 阈值真值、科学效度或因果效果 |
| 独立协议数据 | 核查接口适配和拒绝链 | 正向跨数据集迁移效度 |
| 预测消融 | 界定下游支持性信号与使用边界 | 新预测算法或独立构念验证 |
| 拓扑审计 | 限定当前表示的负结果范围 | 拓扑/GNN 的普遍无效性 |

## 最终判定

C1—C8 均有正文落点、冻结制品、替代解释和不可外推边界。当前没有
主张—证据断链，也没有必须依靠新增实验才能关闭的 P0/P1 内容问题。
主要数据和独立协议审计数据均为公开数据；本文不再使用“内部数据”或
“工业数据”作为贡献依据。
