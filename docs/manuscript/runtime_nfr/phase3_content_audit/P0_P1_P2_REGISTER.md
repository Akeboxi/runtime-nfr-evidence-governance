## 当前前三项审稿意见

1. “规则可以执行，但为什么这些门槛构成研究贡献，而不是作者定义的工作流？”
2. “51.1% 是治理规则按定义产生的比例；除了增加字段，论文证明了什么可检验差异？”
3. “专家总体高分掩盖了硬边界反例与量表天花板；治理适当性是否来自保守措辞？”

对应的最小回答不是增加模型，而是：精确定位最近邻、展示规则反事实和交集、公开专家反例、把阈值正确性主张彻底移除。
