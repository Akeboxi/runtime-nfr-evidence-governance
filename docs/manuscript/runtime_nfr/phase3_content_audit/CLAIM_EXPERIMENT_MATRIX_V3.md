# Runtime NFR Claim–Experiment 矩阵（阶段三关闭版）

## 主线与证伪条件

一句话主张：缺少显式 SLO 时，历史遥测只能形成候选边界；把候选与证据充分性、拒绝理由、责任路由和利益相关者批准权绑定，可把“现在不能直接操作化”变成可审计输出。

该主张不等于新阈值算法、新预测模型、阈值正确性证明或正式 SLO 自动生成。若治理状态不改变后续动作、规则删除不改变状态、专家不能区分阈值合理性与治理适当性，或拒绝路径无法在不兼容输入上保持，则核心机制缺少实证支持。

| ID | 可维持主张 | 直接证据 | 主要替代解释 | 允许结论 | 判定 |
| --- | --- | --- | --- | --- | --- |
| C1 | 历史遥测可批量形成可追溯候选卡 | 8,668 张卡；服务、SLI、单位、窗口、父卡与哈希链；第一轮表达质量评价 | 数量来自冻结设计单元的系统展开，不代表目标正确 | 可构造、可测量、可追溯；候选不等于 SLO | 通过措辞降级 |

## 证据角色去重

| 证据 | 唯一角色 | 禁止承担的角色 |
| --- | --- | --- |
| threshold-only | 暴露治理层增加的证据与责任信息 | 阈值精度或业务效用基线 |
| 规则反事实 | 显示冻结政策改变哪些状态及迁移目的地 | 选择最优门限或证明规则正确 |
| 第二轮专家 | 检查两个评价对象能否被区分 | 利益相关者批准、总体批准率或因果改进 |
| 人工核查 | 验证匹配实现和证据重建 | 阈值正确性、科学效度或因果效果 |
| 独立协议数据集适配 | 验证接口和拒绝门禁 | 正向跨数据集迁移效度 |
| 预测消融 | 检查下游支持性信号与使用边界 | 新预测算法或标签构念验证 |
| 拓扑审计 | 限定当前表示的负结果范围 | 拓扑/GNN 普遍无效 |

## 最终判定

C1—C8 均有正文落点、冻结制品和不可外推边界。内容层面没有要求追加实验；证据不足之处均以责任对象拆分或主张收缩处理。
