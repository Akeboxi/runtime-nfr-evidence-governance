# Runtime NFR 语言最终收口报告

日期：2026-07-30

正文版本：`v0.7-final-review-polished`

## 使用范围

- `research-writing-skill`：只处理主张与证据之间的局部逻辑衔接。
- `academic-humanizer`：审计机械表达、连续防御句、过度主张和不必要重复。
- `nature-polishing`：仅处理英文题名、摘要和关键词；不重写中文全文。
- `statistical-analysis`：复核统计动词、分析单位和区间表述。

`nature-polishing` 的本地共享层目录在当前安装中缺失，因此本轮依据该 skill
可读取的核心说明及题名/摘要、Research、English、通用片段执行有界润色。
该环境缺口没有扩大处理范围，也没有影响中文正文或科学内容。

## Academic-humanizer 诊断

| 模式 | 诊断 | 处理 |
| --- | --- | --- |
| 工作汇报式顺序 | 正文主线已在上一轮改为问题—机制—证据—意义 | 本轮不再重排章节 |
| 连续自我防御 | 必要边界集中在实验职责和有效性威胁 | 保留科学边界，不重复扩写 |
| 过强验证动词 | 摘要、贡献、讨论和外部效度有 4 处强度偏高 | 改为“表明”“支持”“配对证据” |
| 机械英文长句 | 旧英文摘要含多层从句和分号串联 | 拆分为短句并保持中英文主张对齐 |
| 术语漂移 | human in the loop、批准权与可追溯性未完全进入英文关键词 | 统一为 `human-in-the-loop governance`、`traceability` |
| 过程性限制 | 不必要重复已基本清除 | 本轮未删除有效性威胁 |

## 已实施的局部修改

1. 中文摘要将独立数据的作用改为“表明冻结拒绝路径在输入条件不满足时仍能执行”。
2. 引言第二项贡献由“稳定区分”收缩为“提供可被区分的配对证据”。
3. 方法 3.7 补入类别先验与 persistence 的冻结实现定义。
4. 讨论中的“共同确认”改为“共同支持”，外部效度中的“证明”改为“表明”。
5. 英文摘要重写为问题、方法、三组证据、边界和贡献组成的短句结构。
6. 英文关键词增加人在回路治理与可追溯性，保持与中文贡献一致。

## 不变量

- 没有新增或删除实验、数据、阈值、规则、图表和参考文献。
- 69 条参考文献的编号与正文引用集合保持不变。
- 四状态、threshold-only、专家、人工、独立数据、预测和拓扑的关键数字未改变。
- 候选公式、24 h 门禁、时间切分和 bootstrap 单位未改变。
- 英文摘要没有引入中文摘要未支持的新主张。

## 最终判断

中文正文不需要再进行通篇润色。后续语言修改应只来自作者联审中的明确误读
或最终模板中的术语一致性问题；任何科学含义变化都必须触发新版本审计。
