# Runtime NFR 最终定向审稿审计 V2

日期：2026-07-30

审阅对象：`v0.7-final-review-polished`

审阅方法：`review-revision` 的主张—证据—替代解释—边界框架

## 论文地图

- **问题：** 缺少显式 SLO 时，历史遥测不能直接取得规范目标的批准权。
- **方法：** 候选边界—证据审计—治理分流—人工确认的责任链。
- **核心机制证据：** threshold-only 信息暴露、三类规则反事实和边界敏感性。
- **核心评价证据：** 专家对阈值合理性与治理适当性的配对评价。
- **边界证据：** 人工重建、独立协议拒绝、支持性预测信号及当前拓扑表示审计。
- **适用范围：** 两套公开数据中的候选治理和协议执行，不扩张为正式 SLO
  自动生成、生产环境普遍有效或新的预测模型贡献。

## 本轮发现并关闭的具体问题

## P0/P1 判定

- **P0：无开放项。** 创新定位、最近邻对照、核心公式、公开数据来源和三项
  贡献均已形成一致闭环。
- **P1：无阻塞项。** 门禁的政策性、专家非盲化、单一公开测试床、独立数据
  只覆盖拒绝路径以及没有正式 SLO 终点，均已进入方法职责或有效性边界。
- **风险接受：** 若审稿意见只要求更多数据、第三轮专家、重新优化门限、GNN
  或新的正式 SLO 终点，却不能指出现有主张的证据断链，则记录为范围外建议，
  不据此扩张实验。
