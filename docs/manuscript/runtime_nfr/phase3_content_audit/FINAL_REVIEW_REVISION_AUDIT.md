## 本轮发现并修复的具体问题

1. 专家独立性描述容易被误读为对治理机制本身盲化。方法现明确：专家未接触第一轮结果、私有抽样、未来越界和模型结果，但能看到证据状态与建议动作。
2. 高治理评分可能受保守处置偏好影响。内部效度现明确目的性抽样、非概率样本、无法估计总体批准率，也不能构成与 threshold-only 的盲化效用比较。
3. 图 1 可访问原始遥测只覆盖历史窗末端 116–119 个分钟观测。图注现明确“遥测片段”，完整门禁仍来自冻结卡片统计。
4. 图表生成器曾默认产生单图 PDF。阶段三脚本已改为仅生成 SVG、PNG 与灰度 QA 图；整稿和单图 PDF 均留待排版阶段。
