## 1. 总结判断

当前稿已经越过“只有 48 条文献、没有基线、没有消融、图片只是简单柱状图”的阶段。现状是：

- 参考文献已增至 64 条，正文编号连续且全部有引用落点；
- 已核验 16 篇直接或机制最近邻，正文已有最近邻路线表；
- threshold-only、规则删除/换序、专家逐卡配对、人工抽样覆盖、外部拒绝链、五折预测稳定性/校准和拓扑覆盖均有冻结 JSON/CSV；
- 六图已经重做为证据图，而不是单纯美化旧图；
- 38 项 Runtime NFR 相关测试、正式审计、历史完整性审计和投稿内容审计已经通过。

因此，不需要从零执行用户所列的大部分“补工作量”。但也不能直接进入全文润色或投稿排版，因为存在四个新的内容层问题：

1. 正文曾把长尾比率写成 `Q0.99/Q0.50`，而冻结实现实际使用 `(Q0.95−median)/robust_scale`；候选公式和 0.5/720 门槛也未写出。该错误已按冻结代码纠正，仍需加入自动一致性检查。
2. 正文表 1 比内部最近邻证据表更弱，缺少“证据审计”和“外部/独立验证”列，尚未把创新边界正面展示出来。
3. 第二轮专家数据包含一条针对 `R_t=9.997` 硬边界的明确 `STATE_ERROR` 异议，但正文只报告总体高分和 1 个相等配对，未把这一反例用于界定机制。
4. 工作量统计已有卡片、评分、人工判断、外部观测、OOF 行数和审计数，但运行时间、资源需求、制品规模和可复现命令尚未形成正文表格。

当前建议状态：**暂停排版；进入一次有边界的内容强化循环。**

## 3. 是否需要补工作量

### 3.1 必须补，但不需要新增实验

1. **方法可复现性修复。** 固定候选公式、稳健尺度、0.5/720 门槛、零错误例外和真实长尾公式；加入代码—正文一致性测试。
2. **最近邻正文对比表升级。** 从当前 5 列扩展为是否已有 SLO、是否生成候选、是否审计证据、能否拒绝/转交、是否保留批准权、是否独立/外部验证。
3. **已有结果再表达。** 将触发交集、专家状态/队列分层、唯一状态异议、预测校准和工作量表进入正文或补充材料。
4. **核心主线收束。** 摘要和第三项贡献应以“threshold-only 暴露差异＋规则反事实＋专家区分”为主；外部、预测和拓扑降为边界审计，不与方法贡献并列。

### 3.2 建议增加的只读派生分析

这些分析只读取冻结卡片和既有评分，不改阈值、不重新训练：

- threshold-only 隐藏责任动作按 service、SLI、segment/date 和 coverage bucket 分层；
- 四类规则的原状态→反事实状态迁移矩阵；
- 第二轮专家按治理状态、修复/留出队列和专家的配对差值表；
- 现有 OOF 校准箱的可靠性图；
- 复现制品字节数、文件数、命令链和当前测试耗时。

### 3.3 不建议增加

- 第三轮专家、利益相关者批准实验；
- 新外部数据集或为了出现正向外部结果而缩短 24 h 门禁；
- GNN、更多预测模型或重新使用已暴露测试集；
- 0.5/720/10.0 的结果导向重新选择；
- 泛化检索至 70—80 篇参考文献；
- 先进行图片风格美化、Word/PDF 排版或全文语言润色。

## 4. 内容强化退出门槛

满足以下条件后才进入图片重构和全文润色：

- 正文公式与冻结实现一致，并由自动审计检查；
- Claim–Experiment 矩阵中的核心 C1—C4 不再有 Blocker；
- 最近邻检索只剩已公开承认的边界，而不是遗漏的同构方法；
- threshold-only 不被包装成准确率基线，规则反事实不被包装成规则最优性；
- 专家唯一反例和天花板/低方差同时进入正文；
- 外部、预测和拓扑不再占据摘要的主要结果位置；
- 工程工作量表能够区分已测量、可由制品计算和未记录三类成本。
